What it keeps

Attention records

It knows where a visitor slows down, where they skim, and which paragraph they came back to. Reading is a behavior; it is recorded like one.

Hesitation records

Typing pauses. Abandoned fields. Text entered and deleted before submitting. It retains what visitors almost said.

Return memory

It remembers each visitor across sessions and across weeks. A returning subject is met by a page that has already read the previous visit.

Settled reporting

It reports between sessions, not during them. The record you read in the morning is calmer and more true than a live feed.

How it works

  1. One script. It begins with the first pageview. There is no configuration, because the visitor supplies the configuration.
  2. It watches the session. Attention, hesitation, and return are scored on the device itself. Nothing is transmitted anywhere.
  3. Your dashboard fills with people. One profile per subject, refined nightly. Retention follows understanding.
